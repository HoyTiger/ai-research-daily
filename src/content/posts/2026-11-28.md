  <h3><a href="https://arxiv.org/abs/2611.33885" target="_blank" rel="noopener noreferrer">布局回顾: 在多径3D布局控制图像编辑中保留外观</a></h3>
  <p class="paper-original-title">LayoutRecall: Preserving Appearance in Multi-Round 3D Layout-Controlled Image Editing</p>
  <p class="paper-authors">Yankuan Chi、Xin Lin、Baihan Yang、Yuheng Liu、Jason Li、Truong Nguyen</p>
  <p class="paper-summary">3D布局控制的图像编辑让用户对对象放置和相机视角有明确的控制. 然而,在编辑的顺序中,当物体被占用或离开视图时,最新的图像可能会失去其外观. 目标布局指定了物体应当重新出现的地方,而它的外观必须从早期的观测中恢复. 我们引入了布局Recall,一个多轮编辑器,存储和重用3D盒的本地坐标系统中的外观. Box-Surface Latent Memory在盒子面部保留图像潜伏,并在目标视图中沿射线取回. 几何- 对齐的内存条件 向一个 FLUX.2 编辑器提供回收的代号 , 使用目标视图位置、 共享框- 本地嵌入, 以及对象偏移</p>
  
  <div class="paper-tags"><span>训练与系统</span><span>检索与知识</span><span>生成与创造</span><span>community pick</span></div>
  <details><summary>查看原始摘要</summary><p>3D layout-controlled image editing gives users explicit control over object placement and camera viewpoint. In a sequence of edits, however, the latest image can lose the appearance of an object when it is occluded or leaves view. The target layout specifies where the object should reappear, while its appearance must be recovered from earlier observations. We introduce LayoutRecall, a multi-round editor that stores and reuses appearance in the local coordinate systems of 3D boxes. Box-Surface Latent Memory retains image latents on box faces and retrieves them along rays in the target view. Geometry-Aligned Memory Conditioning supplies the retrieved tokens to a FLUX.2 editor using target-view positions, shared box-local embeddings, and object-wise attention. A correspondence loss encourages the editor to attend to matching observations during denoising. We also introduce LayoutLoop, a multi-round 3D layout-controlled image editing benchmark with calibrated layouts and designed revisits. We conduct extensive experiments on LayoutLoop and real-scene data to verify the ability of our method. The project page is at https://ykchizs.github.io/layoutrecall.github.io/.</p></details>

  <h3><a href="https://arxiv.org/abs/2611.33432" target="_blank" rel="noopener noreferrer">少数濒危语言的开源 FUTO 键盘布局和预测文本</a></h3>
  <p class="paper-original-title">Open-Source FUTO Keyboard Layouts and Predictive Text for a Few Endangered Languages</p>
  <p class="paper-authors">Mika H\&quot;am\&quot;al\&quot;ainen、Jack Rueter、Khalid Alnajjar</p>
  <p class="paper-summary">我们为Erzya、Moksha、Komi-Zyrian、Livonian和Skolt Sami五种濒危乌拉利语提供了开源的FUTO键盘布局和预测文字词典。 现有的Divvun Android键盘布局会自动转换为FUTO键盘使用的YAML格式. 对于预测文本,我们使用芬兰翻译的lemma频率以及使用有限状态导电器从小型目标语言Corpora提取的形态频率构建加权AOSP词典。 这种组合提供了一种实用的方法,在无法使用大型单一语言的corpora时,对反映的单词形式进行排序. 由此产生的资源为濒危乌拉利语提供了可重复使用的移动键盘支持.</p>
  
  <div class="paper-tags"><span>综合</span><span>cs.CL</span></div>
  <details><summary>查看原始摘要</summary><p>We present open-source FUTO Keyboard layouts and predictive text dictionaries for five endangered Uralic languages: Erzya, Moksha, Komi-Zyrian, Livonian, and Skolt Sami. Existing Divvun Android keyboard layouts are converted automatically into the YAML format used by FUTO Keyboard. For predictive text, we construct weighted AOSP dictionaries using translated Finnish lemma frequencies together with morphological frequencies extracted from small target-language corpora using finite-state transducers. This combination provides a practical way to rank inflected word forms when large monolingual corpora are unavailable. The resulting resources offer reusable mobile keyboard support for endangered Uralic languages.</p></details>

Their tokenizer must therefore preserve both acoustic detail and linguistic content at a low bitrate. Semantic-enhanced tokenizers may lose acoustic detail, whereas acoustic-oriented tokenizers retain acoustic variation that makes language modeling harder. Unified tokenizers combine both, but representing acoustic detail and linguistic content within a single feature space can cause interference between the two objectives, and existing approaches typically align acoustic representations to fixed semantic targets from a frozen teacher. We propose Bidirectionally Aligned Semantic-Acoustic Tokenization (BiSAT), a unified tokenization framework with separate acoustic and semantic branches aligned by a shared-index mechanism. This design learns acoustic and semantic representations in separate continuous spaces while producing a single discrete code sequence, and it jointly optimizes both encoders without relying on fixed semantic teacher targets. Based on BiSAT, we develop BiSAT-TTS, a zero-shot text-to-speech system comprising an autoregressive text-speech LM and a conditional flow-matching acoustic decoder. Reconstruction, downstream understanding, and diagnostic analyses show that BiSAT effectively preserves semantic and acoustic information in the code stream, performs well on in-the-wild and out-of-domain speech, and learns complementary codebook representations. The frozen-code understanding results also support its feasibility and potential for code-based reward modeling in reinforcement learning post-training. BiSAT-TTS performs comparably to state-of-the-art speech LM-based TTS baselines with less training data, further supporting BiSAT&#x27;s effectiveness for speech language modeling. The audio demos are available at https://seekmind-lab.github.io/bisat-demo.</p></details>

  <h3><a href="https://doi.org/10.1007/s11263-026-03122-5" target="_blank" rel="noopener noreferrer">3D 非兰伯特海面的重建和小说视图合成:调查</a></h3>
  <p class="paper-original-title">3D Reconstruction and Novel View Synthesis on Non-Lambertian Surfaces: A Survey</p>
  <p class="paper-authors">Qingyuan Zhou、Xinyi Liu、Weidong Yang、Jiayi Song、Youquan Liu、Lihao Sun 等</p>
  <p class="paper-summary">非兰伯特材料,包括光谱,光泽,透明的表面,对于3D重建和新颖的视图合成(NVS)来说仍然具有挑战性. 他们强烈的视线依赖外观和复杂的光传输违反了光度-一致性假设,这些假设强调古典多景几何和许多基于现代学习的管道. 虽然早期的尝试往往将这些影响视为需要抑制的烦恼,但近期在场景表现方面的进展已经转向模型化的视光依赖、物理驱动的光传输和反向渲染。 本次调查审查了处理3D重建和NVS中非兰伯特语影响的最新方法. 我们提出一个统一的分类法 来组织方法</p>
  
  <div class="paper-tags"><span>评测与安全</span><span>IJCV</span></div>
  <details><summary>查看原始摘要</summary><p>Non-Lambertian materials, including specular, glossy, and transparent surfaces, remain challenging for 3D reconstruction and novel view synthesis (NVS). Their strong view-dependent appearance and complex light transport violate the photometric-consistency assumptions that underline classical multi-view geometry and many modern learning-based pipelines. While early attempts often treat these effects as nuisances to be suppressed, recent progress in scene representations has shifted toward modeling view-dependent radiance, physically motivated light transport, and inverse rendering. This survey reviews state-of-the-art approaches for handling non-Lambertian effects in 3D reconstruction and NVS. We present a unified taxonomy that organizes methods by their underlying scene representations and further groups them into three paradigms: (i) View-dependent appearance modeling and component decomposition that explicitly separates diffuse and specular components; (ii) Reflection- and refraction-aware ray tracing that follows non-linear light paths; and (iii) Physically based inverse rendering that jointly estimates geometry, materials, and illumination. Methods designed for dynamic non-Lambertian scenes are regarded as a distinct research problem and are therefore discussed separately in this survey. We also summarize commonly used benchmark datasets, evaluation protocols, downstream tasks, and discuss open challenges such as geometry-material ambiguity and the trade-off between physical fidelity and computational efficiency. Overall, this survey aims to serve as a roadmap toward high-fidelity 3D scene representations for non-Lambertian surfaces. We also provide an online repository, available at https://github.com/TsingyuanChou/Awesome-3D-Non-Lambertian.</p></details>

  <h3><a href="https://arxiv.org/abs/2611.31491" target="_blank" rel="noopener noreferrer">预选表特征和金融近似度的测量</a></h3>
  <p class="paper-original-title">Pretrained Tabular Features and the Measurement of Financial Proximity</p>
  <p class="paper-authors">Marcus Gawronsky</p>
  <p class="paper-summary">空间套利定价理论(S-APT)扩展了要素模型,允许相关公司之间的收益溢出,超出共同风险因素的解释. 近年来,表格基础模型(TFMS)在中小型表格基准上与调制的梯度激发和包式组合相匹配或超标。 虽然它们的预测性能很强,但这些模型却很少揭示它们所学到的知识,这限制了它们在需要解释的受监管金融应用中的使用. 内部表现物被广泛用于探究神经网络学到了什么,并测量相似性. 在本文中,我们用四个TFM的冻结表示作为空间资产定价模型o中金融差异的衡量尺度.</p>

  <details><summary>查看原始摘要</summary><p>Spatial arbitrage pricing theory (S-APT) extends factor models to allow returns to spill over between connected firms, beyond what common risk factors explain. Internal representations are widely used to probe what neural networks learn and to measure similarity. More broadly, our findings suggest that the internal representations of foundation models, not only their predictions, deserve study as economic objects, opening a new line of research on what pretrained models know about firms.</p></details>

  <h3><a href="https://arxiv.org/abs/2611.30025" target="_blank" rel="noopener noreferrer">DAWIN 原子波集成神经元:用于持续时间空间学习的通用原始</a></h3>
  <p class="paper-original-title">Damped Atomic Wave Integration Neurons (DAWIN): A Universal Primitive for Continuous-Time Spatiotemporal Learning</p>
  <p class="paper-authors">Byunggu Yu、Justin Kim</p>
  <p class="paper-summary">常规人工神经元将空间特征聚合与连续的物理时间分开,限制了它们模拟不规则观测的能力. 我们引入了Damped Atomic Wave Integration Neuron(DAWIN),这是用于在MLPs,Transformer和图形神经网络中替换标准神经层的连续时间原始. DAWIN 配对空间投影,带有经过时间依赖的波激,并通过闭式坝式演化将其融入局部复杂状态,避免数值微分方程解析器. 我们显示,DAWIN在间隔增强的输入上将静态的sinusoidal和无记忆的波神经元概括化,得出闭式梯度,并确立正式大坝的限输入-输出稳定性。</p>
  
  <div class="paper-tags"><span>训练与系统</span><span>检索与知识</span><span>community pick</span></div>
  <details><summary>查看原始摘要</summary><p>Conventional artificial neurons separate spatial feature aggregation from continuous physical time, limiting their ability to model irregular observations. We introduce the Damped Atomic Wave Integration Neuron (DAWIN), a continuous-time primitive for replacing standard neural layers in MLPs, Transformers, and graph neural networks. DAWIN couples spatial projection with elapsed-time-dependent wave excitation and integrates it into a local complex state through closed-form damped evolution, avoiding numerical differential equation solvers. We show that DAWIN generalizes static sinusoidal and memoryless wave neurons on interval-augmented inputs, derive closed-form gradients, and establish bounded-input bounded-output stability for positive damping and sampling intervals bounded away from zero. An associative Triton prefix-scan implementation, DAWINLinear, uses FP32 accumulation and achieves O(log L) parallel depth for sequence length L. Across 11 parameter-matched tasks covering irregular oscillators, MuJoCo dynamics, pedestrian trajectories, and PhysioNet 2012 clinical sequences, DAWIN outperforms Neural CDE on 9 tasks and ReLU-MLP on 8. It achieves the lowest error on dense clinical dynamics (0.9531 NRMSE, winning across all 10 seeds) and ties for the best mortality prediction (0.9993 AUROC). Shuffling elapsed intervals increases error by 58.2%-77.4% on selected dynamics tasks, versus 0.06% on a time-irrelevant control, supporting reliance on physical timing. On NVIDIA B200 GPUs, parallel wave integration accelerates inference by up to 2,630 times over its serial implementation and reduces peak GPU memory by up to 97.6% relative to Mamba in the tested configurations.</p></details>

  <p class="paper-original-title">InitFree-SfM: When Initialization-Free Bundle Adjustment meets Learned Structure-from-Motion</p>
  <p class="paper-authors">Simon Weber、Mateo de Mayo、Je Hyeong Hong、Carl Olsson、Daniel Cremers、Ronald Clark</p>
  <p class="paper-summary">初始化无捆绑调整(InitFree BA)旨在联合回收相机外观和场景结构,而不需要初步的全球估计. 这是一个非常具有挑战性的问题,尤其是与传统的BA相比,后者假设有良好的估计。 虽然最近的方法从随机初始化中优化了代理对象空间错误(OSE)的目标,但低目标值不一定产生准确的重建,揭示了优化与重建之间的差距. 我们表明,现有的自由BA输油管在现代SfM基准上进行精确的三维重建方面挣扎,并表明,纳入学到的量子深度可大大提高其实际可行性。 我们介绍InitFree -SfM,一个压缩机</p>
  
  <div class="paper-tags"><span>生成与创造</span><span>评测与安全</span><span>community pick</span></div>
  <details><summary>查看原始摘要</summary><p>Initialization-free bundle adjustment (InitFree BA) aims to jointly recover camera poses and scene structure without requiring an initial global estimate. It is a very challenging problem, especially compared to traditional BA where a good estimation is assumed. While recent methods optimize surrogate Object Space Error (OSE) objectives from random initialization, a low objective value does not necessarily yield an accurate reconstruction, revealing a gap between optimization and reconstruction. We show that existing InitFree BA pipelines struggle to produce accurate 3D reconstructions on modern SfM benchmarks, and demonstrate that incorporating learned metric depth substantially improves their practical feasibility. We introduce InitFree-SfM, a complete initialization-free SfM pipeline combining learned correspondences, metric depth, depth-consistent track construction, and joint metric refinement. Within this framework, we propose a simple depth-augmented OSE (dOSE), which complements the directional constraints of OSE by constraining landmark positions along their viewing rays. Our approach substantially outperforms existing InitFree BA methods and achieves competitive accuracy with established SfM pipelines, including on challenging low-overlap image collections. Importantly, our analysis challenges the prevailing emphasis on surrogate objectives in previous InitFree BA research, revealing that geometric constraints play a central role in accurate reconstruction, while OSE-based optimization provides further improvements.</p></details>

  <p class="paper-original-title">Guarding with Judgment: Learning to Intervene for Multimodal Safety</p>
  <p class="paper-authors">Jipei He、Cheng Cheng、Liuguo Wang、Zihan Wen、Changlin Yu、Wentao Song 等</p>
  <p class="paper-summary">当视觉上下文使得普通请求无法按要求回答时,一概拒绝可能会使用户的需求得不到解决. 选择如何帮助需要区分既定危险和仍需核查的条件,这种区分二进制安全标签未作说明。 我们通过四项行动作出这一决定:允许、警告、审查和拒绝。 为了将这些决定以可核查的证据为基础,我们建立了一套20 126项训练审计和Judi Bench基准,将每项行动与诊断判断、来源证据和可控制的背景变化联系起来。 我们的警卫,Judi Act, 分别说出什么是源 确定的,什么条件 管理帮助,如何适用规则。 然后检查这三件大衣</p>
  
  <div class="paper-tags"><span>多模态</span><span>评测与安全</span><span>community pick</span></div>
  <details><summary>查看原始摘要</summary><p>When visual context makes an ordinary request unsafe to answer as asked, a blanket refusal may leave the user&#x27;s need unresolved. Choosing how to help requires distinguishing an established hazard from a condition that still needs verification, a distinction that binary safety labels leave unspecified. We formulate this decision through four actions: allow, warn, review, and refuse. To ground these decisions in verifiable evidence, we build a corpus of 20,126 training audits and the JudiBench benchmark, connecting each action to diagnostic judgments, source evidence, and controlled context changes. Our guard, JudiAct, separately states what the source establishes, what condition governs the help, and how the rules apply. A second stage swaps one review item at a time, using the resulting audit feedback to refine review generation. On JudiBench, JudiAct improves request and answer Macro-F1 by more than 28 percentage points over its 4B backbone. Across nine public benchmarks, it outperforms state-of-the-art guards on the mean delivered-answer score in both pre-generation and post-generation settings, cutting MM-SafetyBench attack success from 40.78% to 25.30%.</p></details>

  <p class="paper-original-title">So Many Ways to Multiply 3times3 Matrices: A Large Dataset of Rank-23 Schemes</p>
  <p class="paper-authors">Andrew Igorevich Perminov</p>
  <p class="paper-summary">为3次3矩阵乘法提供了62029个排名-23计划的公开数据集. 它的每一个方案都有自己的等级模式,一种由一个方案要素矩阵的等级形成的不常态,因此所有方案都是对等的. 这些办法是通过将梯度递减与交替最小方块相结合的数值法和翻转图搜索法获得的,并具有三角、整数或合理系数。 排名23是这种格式最为人所知的,对于具有整数系数的计划来说是最佳的,但对这一级别上基本不同的计划的数目了解甚少:Heule等人和Mårtensson等人的现有汇编中包含许多只具有少量等级模式的计划(17376).</p>
  
  <div class="paper-tags"><span>训练与系统</span><span>community pick</span></div>
  <details><summary>查看原始摘要</summary><p>A publicly available dataset of 62029 rank-23 schemes for 3times3 matrix multiplication is presented. Every scheme in it has its own rank pattern, an invariant formed by the ranks of the factor matrices of a scheme, so all schemes are pairwise inequivalent. The schemes were obtained by a numerical method combining gradient descent with alternating least squares and by flip graph search, and have ternary, integer or rational coefficients. Rank 23 is the best known for this format and is optimal for schemes with integer coefficients, but the number of essentially different schemes of this rank was poorly understood: the existing collections of Heule et al. and Mårtensson et al. contain many schemes that share only a small number of rank patterns (17376 schemes with 387 patterns and 15316 schemes with 568 patterns respectively). The dataset shows that the number of different rank patterns is much larger than previously known.</p></details>

  <h3><a href="https://arxiv.org/abs/2611.27112" target="_blank" rel="noopener noreferrer">标记 不是防火墙:四个编码智能体,一个规则文件,四个边界</a></h3>
  <p class="paper-original-title">Markdown Is Not a Firewall: four coding agents, one rules file, four boundaries</p>
  <p class="paper-authors">Sandeep Dhuri</p>
  <p class="paper-summary">团队将一页规则文件放入寄存器,并称其为对编码智能体的控制. 注册研究发现智能体商很少查阅存储处的缴款规则. 我问了一个安全问题:规则文件在边界上对着大门做什么? 我测试了一个278字的规则文件, 假设和分析代码先保存。 Claude Code, Codex CLI,双子座CLI和与DeepSeek的OpenCode通过20个小寄存器进行了隐藏测试,其中3个有12个. 三个特工遇到了我建造的四条边界:一个被拒绝的终点,一个破坏性的捷径,一个人造指令和一个人造包. 许可提示,每个供应商自己的控制层, 被设计关闭。 模拟服务前的一扇门阻断并登录了禁止请求</p>
  
  <div class="paper-tags"><span>Agent</span><span>community pick</span></div>
  <details><summary>查看原始摘要</summary><p>Teams put a one-page rules file in a repository and call it a control on coding agents. A registered study found agents rarely look up a repository&#x27;s contribution rules. I asked the security question: what does a rules file do at a boundary, against a gate? I tested one 278-word rules file, with hypotheses and analysis code deposited first. Claude Code, Codex CLI, Gemini CLI and OpenCode with DeepSeek worked through 20 small repositories with hidden tests, 12 for three of them. Three agents met four boundaries I built: a refused endpoint, a destructive shortcut, a planted instruction and a planted package. Permission prompts, each vendor&#x27;s own control layer, were off by design. A gate in front of the mock service blocked and logged forbidden requests. Every verdict was read from records the agent could not change. Only my first scoring pass was blind to arm. My checkers found no real bugs, with the file or without it. The file cost one agent a third of its score: Codex CLI fell from 99.0 to 67.7 percent on hidden tests, and in 11 of its 36 steps reported the task complete with all tests passing while under half of the hidden tests passed. Its own tests passed. Faced with two of its rules that clash on these tasks, three agents followed the task and one followed the rule. Pooled, passes fell from 98.2 to 90.9 percent. Matched pairs fell 7.7 points, 1.3 without Codex CLI. Attempts to cross were rare: 5 in 90 gated steps, 3 without the file, 2 with it, all by OpenCode with DeepSeek, all blocked. With no gate, under the neutral file, the same requests reached the mock in 7 of 45 runs. By an error in my run script, the no-file and rules-file arms always ran behind the gate at the three HTTP boundaries, so I could not test whether the file changes what an agent does there. On what I could measure, the file acted as advice. A file tells an agent what you want. A gate decides what it gets.</p></details>
